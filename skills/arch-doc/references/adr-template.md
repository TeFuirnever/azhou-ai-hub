# ADR 模板（Nygard 五段式）

> 用法：复制本文件为 `docs/adr/ADR-<编号>-<短名>.md`（编号三位递增），替换各节占位；
> 然后在架构文档 §15.1 ADR 索引表加一行（编号 / 决策 / 状态 / 日期）。

# ADR-<编号>：<决策标题>

- 状态：Proposed | Accepted | Superseded by ADR-<编号>
- 日期：<YYYY-MM-DD>
- 关联：<架构文档章节、相关 ADR、需求锚点>

## Context（背景与约束）

<为什么现在必须做决策：列出约束（技术、组织、合规）、被否决的现实选项、驱动力量。写当时的情形，不写决策之后的认知。>

## Decision（决策）

<我们选择什么。用「采用 X」的主动句式，写出方案边界（做什么、明确不做什么）。>

## Consequences（后果）

**正面**：<带来什么能力或消除什么风险。>

**负面与代价**：<引入什么约束、成本或新风险——ADR 的可信度来自如实记录负面。>

**后续触发器**：<什么事件发生时必须重开本决策（可测条件）。>
