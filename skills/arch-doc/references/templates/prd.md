# PRD：<产品或功能名称>

> **MCC 权威 PRD 模板** · 模板版本 `1.3` · 资料校验日期 `2026-09-01`
>
> 本模板是 MCC 仓库内产品需求文档的规范结构。经批准的具体 PRD 是产品意图、范围和成功标准的单一真源。技术设计可以细化实现，不能静默改变 PRD；涉及目标、范围、验收或发布门的变更，必须更新 PRD 并重新评审。
