# LLM Wiki command

Use `/llm-wiki` as the explicit command entry.

Read `llm-wiki/SKILL.md`, inspect existing pages before writing, and use the
configured `llm-wiki` MCP tools when available. Preserve user intent: cite
sources, return the operation receipt, and never delete a page without direct
authorization.

Arguments: `$ARGUMENTS`
