# Super LLM Wiki command

Use `/super-llm-wiki` as the explicit command entry (the compatibility name `/llm-wiki` also triggers).

Read `super-llm-wiki/SKILL.md`, inspect existing pages before writing, and use the
configured `super-llm-wiki` MCP tools when available. Preserve user intent: cite
sources, return the operation receipt, and never delete a page without direct
authorization.

Arguments: `$ARGUMENTS`
