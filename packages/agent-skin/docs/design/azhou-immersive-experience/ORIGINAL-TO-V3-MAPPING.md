## 不得弱化的语义

动画协议ready、宿主控件可操作、叙事文案独立。旧实例迟到释放不得清掉新实例，样式只恢复仍归本实例的值。reduce覆盖运行、设置预览、重播及降级，无强制预览绕过。源码及截图不升级为实机体验结论。真实宿主另注册版本、输入和界限，500ms不是普适SLO。释放前finalReport不能替代释放后查询。缺实机或已加载证据保持待验收，局部测试/合成浏览器/CI不能替代同版宿主。

## P01剩余精确差异

- 身份、安全、可访问性、清理、证据保留。时长、入口、全UI范围、旧仅实验交付及ZCode记录演变，不抹掉历史。
- Endfield指针/滚动/Thunder/胶囊不因旧包存在而自动扩大V3范围，须逐项判定相关性。
- 当前testing.md明确每种语言及整包UT行覆盖率均须≥95%，生产代码适用门禁保留。旧三宿主中的ZCode退役差异显式记录，不推导其他端已通过。
- “首个自有帧500ms提案”与“旧合成夹具退出至输入500ms”是不同指标，禁止混用。
- 本映射关闭的是文档追踪缺失；NH-00当前运行身份/owner及P02协议冻结仍独立验收。场景账本按[V3验证合同](V3-VALIDATION.md)逐项关联正例、负例和关键交叉。
