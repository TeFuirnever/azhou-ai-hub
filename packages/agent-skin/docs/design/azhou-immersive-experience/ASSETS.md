# 阿舟素材设计规格

本文件是拟生成素材的评审参考，不是现有文件完成清单。

## 身份不变量

现有 `assets/azhou/wallpaper-scene-q-v3.png` 的视觉基准为橙发、狐耳和尾巴的 Q 版阿舟，在暖色木质实验室内使用电脑。大头、小身体、短四肢及脸部特征保持一致，不变成正常人体比例动漫角色。服装、主配色、耳尾与道具先在角色参考页固定，再生成动作和场景。

允许重生成素材不等于允许换 IP、复制 Dragon 角色、上传私有素材到任意第三方或改变现有美术许可证。生产前确认输入来源、生成服务与授权范围。代码 MIT、现有美术 CC BY-NC-ND 4.0、品牌条款分别适用。新图分发授权需独立确认，不能自动继承或覆盖现有 NOTICE。

## 拟交付素材

| 资产 | 作用 | 验收 |
| --- | --- | --- |
| 角色参考页 | 正面、侧面、表情及颜色基准 | 人工确认身份，后续图与其比对 |
| 场景母版 | 首页与启动共用空间 | 左侧留白、右侧阿舟、完整宽高适配范围 |
| 静态启动底板 | 设置快照到达前首次呈现 | 使用已批准素材，无用户草稿或旧缓存 |
| 启动关键帧 | 起始、过程及末帧 | 同一角色与镜头，无肢体漂移或突变 |
| 工作区壁纸 | 首页氛围与任务页低干扰模式 | 同一光源和末帧焦点，文本可读 |
| 降级静态图 | 动画禁用、失败及减弱动态偏好 | 不阻塞操作，不闪烁，不擅自改设置 |
| 入口图标 | 仅在审阅决定需要更新时产生 | 不改变身份、安装目标或签名契约 |

素材清单应记录相对文件名、内容摘要、尺寸、色彩空间、透明度、用途、焦点、来源和许可。拒绝丢失元数据、意外 EXIF、敏感内容和不明版权输入。文件预算以现有生产构建器验证为下限，不通过扩大传输限制绕过大图问题。

`assets/private/` 是本地覆盖而非分发目录。现有覆盖只接受规定文件名，不能把候选、Pet 图集和回执混入其中。发布素材只在审阅后进入明确的生产输入，必要的 manifest 和构建校验与素材同一 PR 更新。

## Pet 素材不随场景更新

现有 v2 图集规格为 1536 × 2288，8 × 11 单元，每格 192 × 208。九种状态使用帧数为 6、8、8、4、5、8、6、6、6，另有十六方向和保留中立格，共 74 个使用格和 14 个透明格。以 `pet/theme.json` 及实际工具校验为最终依据，不凭此规格重建已安装 Pet。

角色一致性评审覆盖侧脸、耳尾、衣服、肢体比例及透明边缘。完整方向语义与所有步态尚需真实逐帧审阅，历史 idle、微动和跳跃观察不能替代。素材生成候选保留在专用本地工作目录，不入侵包的受限素材目录。

## 视觉审阅

先审角色页，再审宽屏与窄屏构图，最后审启动到工作区的完整录屏。比较静态关键帧不足以证明交接。新图不得把原生聊天框画进背景。默认无新增音频。减弱动态、禁用动画与跳过应各有明确动作，不把它们合并成一种配置。
