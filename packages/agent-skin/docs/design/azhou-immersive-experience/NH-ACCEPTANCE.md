# 补充验收契约

以下编号仅属于本设计补充包。全部 runtime 状态均为 not_run。不能替代未读取原包的验收编号。以真实录屏确认首屏时序，以结构化事件确认身份、运行和终态，两类证据不能互相代替。

| ID | 触发 | 必须观察到 | 否决条件 |
| --- | --- | --- | --- |
| NH-A01 | Codex 完全退出后从受管阿舟入口启动 | 阿舟自有呈现先于宿主工作区露出；只出现一段动画；最终进入同一被验证宿主 | 对话页先露出、窗口切换露底、动画重播；仅凭 controller 存在判通过 |
| NH-A02 | 修改已保存图片、文字、语言或主题后冷启 | 使用本次有效设置快照，保持原动画时长与素材身份 | 读旧缓存、preview 默认设置、未保存草稿；用系统语言冒充宿主语言 |
| NH-A03 | 设置不存在、读取失败、数据损坏、合法大图 | 已知空记录才走明确默认；错误路径有界退出或明确降级；大记录分块且验证长度摘要 | 失败等同空设置、全局抬高 CDP 上限、任意路径文件读取、静默播放旧图 |
| NH-A04 | 临时页面销毁、先重叠后退休、后继页再次切换 | 原生播放器只播放一次；页面能力按代际撤销并重新证明；不重置总期限 | 复用旧页 ready、给旧页写设置、重装 page player、凭静默计时器断言页面稳定 |
| NH-A05 | 慢预检后进入冷启、动画先完成、宿主先就绪、壁纸关闭或失败 | 所有阶段沿用request.startedAt预算；动画终态与宿主就绪独立；正常可交接时交接；壁纸失败可明确降级进入宿主 | 准入后重置预算、把 disabled 当失败、壁纸无限阻塞、把 native complete伪造成 page ready |
| NH-A06 | cover、播放、交接中跳过或退出；宿主崩溃；到期 | 跳过立即解除自有遮挡且不重播；失败不杀用户宿主；焦点按用户当前意图处理；全部资源回收 | 黑屏、焦点被重复抢回、迟到消息复活窗口、悬挂观察器、超时重置 |
| NH-A07 | 宿主已运行，或重复打开阿舟入口 | 同一宿主激活，既有单实例行为保留，不播放冷启动动画 | 重启宿主、第二个播放器、重复注入、写坏当前设置 |
| NH-A08 | DSH web 与 desktop 各自冷启 | 在被证明支持的最早入口显示阿舟遮罩，客户端确认接管前无可见空档；只播放一次 | 把 immediately:true 或 DOMContentLoaded 当首帧证明；只测 web 就称 desktop 通过 |
| NH-A09 | DSH client 未下载、依赖失败、插件禁用或热重载 | 早期遮罩有独立失败释放；热重载不误当新冷启动；移除插件后宿主可用 | 兜底只存在于未加载 client 中；导航或配置变更重播；遮罩无法撤销 |
| NH-A10 | 两端保存、取消、预览、重启，DSH 多 profile | 原命名空间和数据保持独立；取消不保存，预览不污染；配置刷新与下一次启动语义明确 | Codex 写 DSH DB；跨 profile 混用；镜像成为隐式第二设置权威 |
| NH-A11 | 新构建安装或回退 | 来源、输入、产物、安装、实际运行身份逐层可追踪；真实入口唯一；各端回退验证 | 只编译通过就写已安装；旧页面冒充新版本；未核实共享 DSH profile 就覆盖实体包 |

## 证据计划

在实现前冻结协议，保存原版与候选的输入、运行环境、录屏方法和同一验收动作。评估目录每次新建。至少覆盖普通冷启、保存自定义设置后的冷启、冷启前页换代、热启动、跳过、故障释放和 DSH client 失败。重复次数由原包协议与首次稳定性证据决定，不由本设计虚构通过次数。

录屏从点击前开始，覆盖整个显示器上宿主窗口可能露出的区域。裁剪只看动画窗口会漏掉背后工作区闪现。不得读取聊天内容建立测试夹具，实机录屏使用授权的无敏感内容工作区。记录首个自有可见帧、动画首帧、自然完成、宿主显露、焦点交接，采样间隔和帧率随证据保存。

自动测试覆盖纯状态转换、严格字段、代际身份、读取和分块边界、重复事件、超时清理、热启动及生成包接线。原生与真实浏览器测试要调用生产入口，不能只测 mock 选择器。

## 门禁

修改生产代码后，按当前仓库规则运行 python3 scripts/verify.py。启动生命周期与共享播放器变更需执行 Native、生成表达式、启动浏览器和相关壁纸回归。按 packages/agent-skin/docs/testing.md 保持整包及各语言至少 95% 的 UT 行覆盖率。DSH 构建与产物验证另行执行。只有文档检查通过时，结论必须写 document_checked，不得写产品 PASS。

安装验收按 local-install-sop.md 分端执行。结束当前 Codex 会话的冷启由操作者完成。视觉连续性必须现场或录屏审阅，技术通过不自动构成人工采纳。
