## 本轮边界

保留现有设置、冷启动协调、失败恢复、Pet及安装所有权。扩展现有SkinHostContract、Codex page adapter、DSH adapter，不另造全局Coordinator。参考源码可合法复用，媒体原创重建。当前HEAD为eb467381；PR469已合入fa8967b3。已独立通过101项startup自动测试，但仍须完成契约差异与剩余任务映射，不重复重写已合入修复，不将单元通过当真机验收。

当前Native契约含身份、版本、build、可用能力及拒绝类型，但SkinHostID只有codex。DSH已有独立JS adapter，不能将其源码存在写成Native契约已支持DSH。Codex和DSH的生命周期证据各自绑定，不用一端代另一端。

## 拟议数据边界

- AssetDescriptor记录内容摘要、角色版本、帧/时间基、尺寸、色彩、透明度、许可和来源；运行媒体与可编辑源分开。未批准素材不得进入生产manifest。
- Timeline记录hold、transition和构图轨迹，来自最终素材实测，不由固定12秒或约14秒推导ready。GIF/序列帧也使用该统一时间轴。
- AdapterEvidence记录host/version/build、adapter/schema、document generation、可见surface map与实际能力。缺少必要surface为unsupported，不把零匹配集合当通过。
- Presentation接收画面、时间和已验证surface；controller持有runId、终态、期限、取消和音频释放。异步解码、换页和旧回调不得继承新一代ready。
- 音频独立资源owner；无音轨容器也能使用可选同步声音。静音、reduce、关闭、跳过、失败、隐藏、卸载都能停止自身声音，清理不依赖播放结束。

这些是要在P02冻结的设计数据，不是新增第二套运行时接口。实现前先映射现有对应类型并删去重复项。

## 负例与验收层级

每个组合分别记录not_run/blocked/fail/pass，不以一个总绿灯覆盖未知项。至少覆盖页面与窗口切换、隐藏缓存页、多主页面、Dot中央与右栏、设置/预览/重播、Pet排除、侧板、主题切换及恢复。

动态链额外覆盖解码损坏/超时/拒绝、hold早晚ready、seek失败、资源释放后晚到回调、音频拒绝、无透明支持、背景失败重试、减少动态实时变化、IME及真实键盘输入。只释放自有资源，未知宿主结构回到可操作原生UI。

证据分为来源检查、纯函数/合成fixture、隔离浏览器、真实宿主四层。格式样本不能证明角色质量；角色影片不能证明真实交接；源码与截图不能证明输入可用；DSH Web不能代Desktop。真实宿主采样必须记录版本/build/载荷摘要/设置/窗口条件/实际操作及释放后检查。

## 吞吐检查点

串行瓶颈是角色困难段质量和P02视觉冻结。格式试样、源码复用许可、adapter只读调查可并行，但不拆散同一可验证单元的实现与测试。每单元一份独立证据，冻结后不原地覆盖。私有样本与租约不进入正式设计包。

## P02与最终验收的界限

P02需要参考组合实录、素材真实播放、非生产对照及用户视觉审阅；不要求尚未实施的P03/P04最终交接先通过，以免形成循环依赖。完整候选产品在后续接入阶段及P06按真实宿主验收。P02通过只开放已冻结范围的实施，不升级为全产品ready。新增技术格式试样不改变该门禁。

本轮本地格式探针已运行。2秒、256×144、24fps的抽象testsrc2样本，MP4/H264、WebM/VP9、GIF、APNG均编码后再解码48帧，无解码错误。这仅证明此机器ffmpeg路径能处理这四种格式，不证明宿主支持、透明精度、画质或角色动作。当前ffmpeg编码器列表未提供libwebp；不因此声称其他工具不支持WebP。真实媒体预算不能从这段抽象小样外推。
