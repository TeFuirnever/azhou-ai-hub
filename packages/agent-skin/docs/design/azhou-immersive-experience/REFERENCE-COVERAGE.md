# 参考组合效果覆盖矩阵

本表响应“全面对齐 Codex-Dream-Skin 与 dragon-codex-boot 的配合效果”。此前设计仅充分覆盖原生交接与壁纸，未充分覆盖整窗主题、主题管理、开场分镜、音频和入口差异。此修订撤销把这些遗漏视作已排除范围的假设。

## 证据等级与完成口径

Dream 基线为 `6fc42df48a6a5365011f55cc349e20c038e56d1d`，Dragon 基线为 `c63a203`。下表路径属于对应参考仓库，行号只用于此基线。当前实际组合运行尚未录制，不能据文档或源码宣称组合视觉 parity。

本次直接查看 Dream 的 macOS 首页和任务页已有截图，并只读抽取 Dragon 随附 MP4 的关键帧。MP4 探测结果为 H.264、1920×1080、24fps、14.101秒，含AAC音轨。抽帧证明分镜内容，不证明当前宿主交接成功。既有 Dream 截图可能对应旧版 hero 结构，不是最新 DOM 的验收基准。参考截图与视频不复制进本包，避免授权与其中内容的隐私风险。

## 三方对照协议

先在获准的隔离环境或使用已存在且可确认版本的录屏，记录参考两工具组合。不能为取得证据先改用户当前安装、启动项或关闭正在工作的宿主。缺此证据时保持 reference_live_unverified。

对同一显示器、窗口几何、宿主版本、示例内容和冷热入口分别记录参考组合、Hub trunk、Azhou候选。素材角色不同可以接受，但镜头节奏、面板层次、透明关系、交接和交互必须有对应场景。分别标记参考已证实、候选已证实、平台差异与未决。每个 REF 行都需引用截图、视频片段或可重跑测试，不用一个总分覆盖遗漏。

原生设置与身份安全约束继续有效。12秒与14秒、默认静音与有声、官方图标监听及在线社区范围是新增明确的产品取舍，不应由实现者暗中决定。先完成方案原型与范围裁决，再冻结 NH-10 及对应验收预算。
