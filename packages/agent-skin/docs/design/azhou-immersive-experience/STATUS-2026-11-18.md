## 优先级一：收口无视频基础模式

以下事项不等待最终动态素材：

1. 逐宿主绑定源码、构建、安装与实际加载身份。
2. 完成冷/热启动、设置保存重开、重启保留、恢复及页面切换的真实验证。
3. 单验 Dot 中央会话、右栏及普通页往返，不以侧栏壁纸可见代替整页结果。
4. 验证原生输入、IME、焦点、滚动、菜单和失败释放后的可操作性。
5. 为 DSH 首次 Apply 失败取得可诊断原因；对真实缺口建立失败测试和修复，不用重复成功关闭未知根因。
6. 验证无视频资源与配置仍可构建、安装、启动、设置和恢复；减少动态及静态资源失败另列结果。

Codex 和 DSH 分别记账，一端通过不转移为另一端通过。
