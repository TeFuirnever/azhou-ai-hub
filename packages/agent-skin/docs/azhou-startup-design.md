日期：2026-10-24。本轮仅重做启动动画、必要的启动交接和产物收敛。

## 一手观察与基线

- Git 基线为 `c743c2b`。开始时已有 README 和两个 `.command` 的未提交修改；已完整保存到 `.local/recovery/20261024/source-before.zip`，另有 `before.patch`。
- 源码仍使用爱弥斯文案和默认图片；用户目录 `~/Applications/Codex.app/Contents/Resources/web` 才含上一轮阿舟替换。两个 `.command` 优先打开这份安装副本，导致编辑源码与观察安装副本可能脱节。
- 当前屏幕报告：1512×982 点、3024×1964 像素、2× Retina、120 Hz。既有原生播放器实际窗口 1000×658 点；渲染时钟的实际 rAF 频率不等于屏幕刷新率。
- 基线通过原有 `Native/App.swift` 加当前安装副本的逐字节 web 资源播放。观察包装器仅增加置顶以免其他窗口遮住动画；没有打开、隐藏或退出主程序。第一次非置顶观察被其他窗口遮挡并超时，不能当作完整播放通过；随后置顶完整播放自然到达 `ANIMATION COMPLETE` / 12.00 秒。
- 基线录屏保留为 `before-full-window.mov`。早期不完整 / 裁切的诊断录屏不作为最终基线证据。

审美问题：中心头像实际占画面面积较小；黑底、雷达和低亮度小字使人物与品牌信息分散；先碎片化再描线的阶段与“实验室做事”缺少动作因果；后半段变为成人比例插画，与 Q 版开场不连贯；收束采用整画面压扁和亮线，与温暖陪伴主题不合。

## 素材选择

实际打开并核查了指定头像和实验室图。头像为 256×256 RGBA 半身像，无法提供手部动作或完整桌前姿态；实验室图为 1536×1024 RGB，已包含成人比例人物和环境，没有可独立移动的角色层。

选择素材库已正式采用的 Q 版分支：`assets/characters/azhou-chibi-pet/v1.0.0/images/04-working.png`。该包 `CHARACTER-SPEC.md` 明确它是女性 v2 的 Q 版拟人分支。原图为 1254×1254 RGBA，包含阿舟、桌子、电脑和书。它仍是一张静态合成插画，没有手臂 / 头部 / 桌面的独立图层，也没有连续动作帧。

画面中以 540×540 点显示该透明插画；在本机 2× 显示下需 1080×1080 像素，原图有清晰度余量。以固定桌面、局部小幅连续形变实现敲键、前倾、抬头和眨眼，避免需要补画遮挡区域的大转身、大位移。头部变形权重明确避开电脑，手部权重在桌边前归零，尾部仅作延迟响应。背景和台灯由现有网页中的 SVG / CSS 绘制，保持清晰。

`tools/prepare-azhou-assets.py` 仅逐字节复制原图并生成本地 data URL 加载文件，不修改素材库。输出 `assets/private/` 受 Git ignore 和构建核查保护；包含素材的 `.app`、录屏和恢复包均不得上传到公开仓库。

## 分镜与时间轴

原版 12 秒中的碎片 / 描线占用了约 3 秒，彩色画面仅在后半程出现。本版取消这段无角色动作的转场，把时间用于桌前动作和同一构图中的稳定阅读。粗演采用 7.8 秒，实际窗口完整播放后保留该时长。

| 时段 | 动作与信息 |
| --- | --- |
| 0–0.6 s | 暖色实验室显现；阿舟和工作台淡入并落稳，视觉焦点在人物。 |
| 0.6–2.65 s | 阿舟轻微前倾，左右手交替敲键；电脑引出单条启动信号。标题 1.38–1.93 s 显现，英文小字 1.98–2.36 s 显现。 |
| 2.65–3.55 s | 手部动作停止，阿舟抬头轻点头；灯光稳定，信号到达 CODEX 标记；字幕 3.22–3.64 s 显现。 |
| 3.55–7.05 s | 固定构图；三项文案保持阅读，角色不进行高幅度循环动作。 |
| 7.05–7.8 s | 辅助信号收束，角色保持稳定；动画完成后由原生窗口激活主程序并淡出。 |

标题是 `阿舟的 Agent 实验室`，排为两行但文本内容不变。英文小字为 `AZHOU / AGENT LAB`；字幕为 `和阿舟一起，把想法做出来。`。全程没有将动画百分比冒充主程序加载进度。

粗演后精修：左右手改为错开的五次敲键；增加头部预备动作与回落；使电脑区域退出头部变形权重；阅读期去掉多余循环动作。粗演证据与最终证据分别保留。

## 交接选择

沿用既有 AppKit + WKWebView 独立窗口基础，预览与正式启动共用一个应用。正常启动准备 / 复用真实主程序，动画结束才激活它。原 CDP 注入、壁纸和图片设置路径保留为历史实现，不参与本轮正常构建。

应用身份按路径、真实路径、Bundle ID 和主可执行文件核对，不能只按名称判断重复。LaunchServices 的 completion 只说明应用启动结果，不能证明聊天页或模型已经就绪。验收因此分开记录目标进程、激活请求、前台观察和启动器退出。

## 验证证据边界

WebKit 关键帧截图仅证明对应画面。连续播放以无快照干扰的完整录屏为主，关键截图从录屏提取；`requestAnimationFrame` 间隔和 JS 提交时间仅是辅助采样，不代表 GPU / 合成线程的完整性能。冷启动如果会中断用户当前工作，则明确未覆盖，不用模拟测试替代。
