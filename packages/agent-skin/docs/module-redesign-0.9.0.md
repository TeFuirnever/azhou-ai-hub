日期：2026-10-28。范围为本地候选源码与隔离验证；不表示已安装、在官方应用中完成注入、获得人工视觉批准或对外发布。

## 已确认的产品行为

应用显示名为“阿舟 AI 实验室 / Azhou AI Lab”，入口和设置身份显示独立 bot 头像及“阿舟 / Azhou”。技术包仍为 `agent-skin`；Bundle ID、可执行文件、物理安装路径、日志路径和设置数据库均保留现有身份。

语言支持简体中文与英文，直接跟随官方页面根节点的 `lang`；深浅色与配色跟随官方 `data-theme` 和颜色令牌。没有阿舟自己的语言／主题选择器，没有新增对应持久化字段。原生入口在官方页面尚不可用时使用系统语言回退，不另建偏好存储。

上述页面来源通过当前安装包代码只读核对：`setup-runtime-6a914457ea0b.js` 将官方设置语言写入页面根节点，`app-theme-979817044ac4.js` 写入实际主题并应用配色。实现只读取这些显示状态，观察根节点的指定属性，不读取对话内容，不导入或复制官方实现。颜色取自 `--app-color-background-surface`、`--app-color-text-foreground` 等已核验令牌，兼容既有 surface/text 令牌。

## 保留的约束

- 12 秒阶段结构和按时间戳推进的时钟保持；默认头像、背景与 Pet 不因入口 bot 头像而替换。
- 保存、取消、冲突、配额、超时、事务提交与版本变化关闭数据库的行为继续由原设置模块负责。
- 官方语言切换更新标签、提示与辅助功能名称，不销毁设置面板，也不覆盖正在编辑的草稿或已经保存的个人文字。
- 页面消息仍验证 source、frame、runId 与阶段；新增显示状态经受控参数和句柄同步，不开放新消息动作。
- 主题观察器随控制器销毁而断开；图片、位图、rAF、定时器与订阅沿现有生命周期释放。
- 物理入口继续为 `~/Applications/阿舟启动 Codex.app`；本地化显示名不构成安装归属证明。安装器的源归属和完整性检查不因更名而放宽。
- `entry-avatar.png` 是单独提供的私有输入，原图不进入 Git；通过现有构建清单绑定，不写入用户的图片设置记录。

## 审视依据与性能口径

采用 [Emil Design Engineering](https://github.com/emilkowalski/skills/blob/main/skills/emil-design-eng/SKILL.md) 的反馈、频率和界面一致性原则，以及 [Animation Performance](https://github.com/emilkowalski/skills/blob/main/skills/animation-performance/SKILL.md) 与 [web.dev 动画指南](https://web.dev/articles/animations-guide) 的按渲染阶段诊断方法。官方语言／主题是唯一偏好来源，保持界面与 [Apple HIG Motion](https://developer.apple.com/design/human-interface-guidelines/motion/) 的可取消、减少动态要求一致。

性能数据必须注明输入、窗口、DPR 与测量范围。rAF 间隔和 JavaScript Canvas 提交耗时不等于 GPU、合成器或屏幕呈现 FPS；静态绘制减少也不自动证明实际设备 FPS 提升。旧版 7.8 秒 WebGL 播放器的数据不能用于证明本次 12 秒 Canvas 实现。

最终私有输入在隔离 Chrome 的一次 12 秒完整预览中，窗口为 1512 × 889、DPR 2：722 次 rAF 调度对应 449 次场景绘制；rAF 间隔中位数／p95 为 16.7ms，实际 Canvas 提交中位数 0.1ms、p95 0.9ms。完成后被跟踪的图片、位图、离屏 Canvas、Path2D、rAF 和 Object URL 均为零存活。该测量不访问官方进程，不代表真实宿主或 WKWebView 的屏幕呈现 FPS。
