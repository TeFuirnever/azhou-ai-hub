---
description: 在浏览器打开工作台的会话仪表盘
---

从本机浏览器打开阿舟 Agent 工作台的会话仪表盘。页面每秒读取最新活动会话的统计和本机资源状态。

1. 探测本机服务。

   ```bash
   curl -fsS -m 2 http://127.0.0.1:7423/api/sessions
   ```

2. 服务未运行时，用当前系统的后台进程入口启动。插件目录是本插件的安装位置。

   ```bash
   node "<插件目录>/dashboard/server.mjs"
   ```

3. 用本机浏览器打开 `http://127.0.0.1:7423`。使用其他端口时，启动命令加 `--port N`，并同步替换地址。

会话统计来自本机 ZCode usage 数据库。需要停止服务时，结束对应的 Node.js 进程。

用户附加要求：$ARGUMENTS
