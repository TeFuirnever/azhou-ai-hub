# dsh-translate-docs

本 Skill 仅用于当前项目。用户授权、项目 AGENTS.md 和实际宿主能力优先。

## 调用与分流

此处是扩展流程，用户点名时使用；普通文档修改直接遵循项目双语同步规则，不因另一 Skill 提及翻译就启动全套流程。两种语言地位相同，本次哪一侧被作者改动，哪一侧就是该次更新的源；不是永久 English-first。

- 已有 pair 单侧变化：最小增量路径，不重译未变整篇。
- 无 counterpart：整篇路径。
- 改名/删除：按本项目命名及实际 sidecar/索引规则成组处理，不能留下单边文档或悬空链接。
- 双侧变化、无可靠共同基线或无法对齐：人工逐段合并，不能任选一侧覆盖另一侧。

冻结历史不翻译、不重封、不修出站链接。生成源先修 owner 再生成，不手改生成文本。

## 增量路径

使用现有 briefing 工具；若项目没有，直接从准确 diff 与上一致版本整理最小简报：变更单元的旧源文、当前源文、当前译文、相邻上下文、相关术语和首次出现位置。按段落/表格行/列表项对齐，实在不能才扩大到章节/全文；不擅自新增 DSH 的配对数据库或调用不存在的 pnpm 命令。

只有两侧原本逐字相同的代码块发生机械变化时，可机械同步后验证结构；涉及 prose 就在简报范围翻译并逐命题复核。不重读整套历史来处理一个明确更新，不改未触及的已审文字。已获授权且宿主有委派能力时可以把简报交给独立翻译者；否则自己完成并单独复核，不虚构独立审查。

## 整篇路径与质量

先读当前文档规范、术语/既有译法与相邻风格样本。按语义单元用目标语言重述，边写边保持结构；再对照原文逐条核对主体、条件、时机、must/may/never、例外、错误、权限及恢复，最后脱离原文独立通读，重写不自然的句子，不能只替换词语。

保留标题层级、表格行列和顺序、列表类型/编号/数量、强调及内联代码。代码块、命令、字段等按实际合同逐字保留，不能为了译文流畅改行为。链接保持语义目标和 query/fragment；当前双语集合内指向对应语言页面，集合外目标不擅改，缺 counterpart 记为问题。

本项目术语优先。未收录术语查既有官方/开源译法；没有可靠依据时保留原词并列为待定，不临时发明术语。译审决定若有术语 owner，则更新 owner 和范围内受影响用法，而非只补一行。只写最终译文，不把过程笔记放进正文。

## 完成 pair

使用本项目真实文件命名（公开入口是 `README.md` / `README.zh-CN.md`），不机械创建 DSH `.zh.md`/`.i18n.yaml`。有实际配对 hash/sidecar 时，只有语义审查完成后才对明确 pair 重新记录，不能整仓盖章；无此机制就报告人工配对检查。

检查链接、结构、术语和双侧意义，并运行适用项目门禁。格式/hash 通过不证明翻译质量。交付区分新建、最小更新、移动/删除、待定术语与未核实项，不自动提交或发布。

来源、适配边界和许可证见 [provenance.md](provenance.md)。
