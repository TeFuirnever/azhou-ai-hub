# agent-experience

本 Skill 仅用于当前项目。用户授权、项目 AGENTS.md 和实际宿主能力优先。

## 发现与上下文

- 先确认当前宿主实际挂载的工具和参数合同；源码存在不证明本会话能调用。区分已提供、可检索、不可用的信息。
- 首层只暴露用途、可用动作和必要约束；细节按需读取。每个延迟资源都有可识别描述和实际可用的获取入口，不能只有“需要时再查”。
- 权限、破坏性效果和动作前必需的校验保持在动作前可见。不要为了省上下文把关键约束藏在调用之后。
- 返回有界结果及稳定 ID/路径，提供获取详情的方式。带上少量可能用到的邻接上下文，例如回复前的几条消息；明确截断、遗漏和继续读取方法，不倾倒整份日志。

## 工具定义

- 说明可观察行为与返回结果，删除无助于选择/使用工具的内部实现、结果中自然可见的标记、显而易见的失败常识。
- 默认值、范围、配对和何时设置等规则放在对应参数。随配置变化的描述优先归入该参数；不能以精简为由删除跨参数约束。
- 一个事实只写在一个合适位置；系统提示不重抄工具定义，工具描述不重抄参数规则，一个工具不承担另一个工具的说明。
- 修改工具定义时，在相同宿主、工具集合和任务下比较首轮提示 token；拿不到计数就说明未测，字数不是 token 测量。
- 同时检查真实任务成功率、搜索次数、重复读取、错误和总工作量。首轮变短但后续找不到资源或反复检索，不算净收益。
