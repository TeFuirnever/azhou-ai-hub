# dsh-error-handling

本 Skill 仅用于当前项目。用户授权、项目 AGENTS.md 和实际宿主能力优先。

1. 识别输入边界、状态所有者、提交点、报告者和清理者；使用项目已有的结构化错误和原因。
2. 分别表达副作用未发生、部分发生、已提交或未知；捕获异常不等于回滚。
3. 未知结果时停止依赖它的操作并由状态所有者对账；仅在安全、有限、可取消且明确负责时重试。
4. 报告用户可执行的下一步，保留意外错误；错误报告失败时使用独立回退。

来源、适配边界和许可证见 [provenance.md](provenance.md)。
