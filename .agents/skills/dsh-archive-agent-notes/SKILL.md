# dsh-archive-agent-notes

本 Skill 仅用于当前项目。用户授权、项目 AGENTS.md 和实际宿主能力优先。

## 先确定记录的合同

读取本项目现有决策/归档规则、记录所有者、授权范围和入站引用；用当前代码、配置、文档与较新决定核对事实。字数、年龄和“已经实现”只帮助找候选，不决定删除或归档。不按配额清理。

每次新增记录，检查同一决定、机制或被否决替代方案的旧记录。只有新 owner 吸收全部独有命题时才属于完全替代；部分替代保留独立理由并交叉链接，不能抹去兼容义务、负面保证或恢复条件。

## 逐项分类

| 状态 | 未来价值 | 处理 |
| --- | --- | --- |
| 已实现 | 仍指导架构、归属、安全、兼容、持久/协议语义或重新引入条件 | 保持活跃，即使很短或实现是机械改名 |
| 已实现 | 实质决定已结束，不再指导当前修改但历史理由有价值 | 归档候选 |
| 已实现 | 仅小型 UI 调整或纯机械过程，没有独有决定 | 删除候选，先核对保留政策与授权 |
| 拟议 | 仍在考虑 | 保持拟议，不归档冒充完成；放弃时记录真实拒绝理由 |
| 已拒绝 | 仍能防止一个合理且诱人的错误选择 | 保留为防误判依据 |
| 已拒绝 | 前提已失效，且不再有独立防误判价值 | 删除候选，不用归档规避判断 |

性能修复、新能力、重要行为改变并不因“已实现”自动成为机械记录。复核同类记录使用一致原则；真正边界案例保留理由供审阅。

## 执行与恢复

- 只修改已获授权且有明确归属的记录；既存任务、未解决决定或记忆没有因此获得删除/写入权限。范围不含执行时只交付分类。
- 有双语/sidecar/索引时按一组处理，修复活跃文档的入站链接；引用当前行为的链接改到当前权威，确实引用历史的才指向档案。
- 冻结档案只保留原始正文，不翻译、不格式化、不修出站链接。仅按现有机制添加归档日期/元数据并更新封印，先证明旧封印未变再追加新项。没有 DSH 的 triplet/manifest 机制时不凭空创建，也不运行其专用命令。
- 恢复先验证档案完整性，在现有规则允许的活跃位置形成恢复版本并保留历史；不能原地解封或覆盖旧档案。新的现行事实在恢复版本重新核实。
- 检查移入/移出、双语及入站链接一致性和项目规定的验证。交付逐项 keep/archive/delete/reject/restore、理由、受影响引用、未决项与实际执行结果；分类建议不等于已经删除。
