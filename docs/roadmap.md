# Roadmap

Roadmap items describe outcomes, not promises. Accepted work moves to a GitHub issue with an owner and evidence target.

## Next

- Create <code>good first issue</code> tasks that each close one reproducible failure.

## Later

- Add more independently installable skills under the same standard.
- Generate SBOM/provenance artifacts when the project ships downloadable release artifacts, not before.
- Add a documentation site only when repository Markdown is no longer sufficient; the repository remains the authority.

Propose roadmap changes through the [skill request form](https://github.com/TeFuirnever/azhou-ai-hub/issues/new?template=skill-request.yml) or [Discussions](https://github.com/TeFuirnever/azhou-ai-hub/discussions).
