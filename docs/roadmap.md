# Roadmap

Roadmap items describe outcomes, not promises. Accepted work moves to a GitHub issue with an owner and evidence target.

## Next

- Create <code>good first issue</code> tasks that each close one reproducible failure.

## Later

- Candidate import can revalidate an existing reviewed Pet for a new root. The maintainer Mac's App and Pet receipts have since been handed off to the Hub package and the former local checkouts retired. General Hub adapter install/uninstall plans still need a supported native destination/state/uninstall contract. Host startup playback, wallpaper apply/restore, Pet selection and visual acceptance remain to be checked separately; see the [local handoff record](../evidence/optional-integrations-local-handoff-2026-10-26.md).
- Consider shared character/export logic only when real consumers need it; a unified character system and richer Pet motion are not delivered by the current migration.
- Add more independently installable skills under the same standard.
- Generate SBOM/provenance artifacts when the project ships downloadable release artifacts, not before.
- Add a documentation site only when repository Markdown is no longer sufficient; the repository remains the authority.

Propose roadmap changes through the [skill request form](https://github.com/TeFuirnever/azhou-ai-hub/issues/new?template=skill-request.yml) or [Discussions](https://github.com/TeFuirnever/azhou-ai-hub/discussions).
