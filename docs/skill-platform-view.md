# Skill platform view

This page is a derived, per-skill summary of the [support matrix](support-matrix.md): one row per canonical skill across harnesses (Codex, Claude Code, zcode, other compatible harnesses) and operating systems (Linux, macOS, Windows). `docs/support-matrix.md` stays the single authority — when the two disagree, the matrix wins and this page must be corrected to match it.

The derivation adds no claims. Every table cell below is either a status token from the matrix vocabulary (supported / host-dependent / not claimed, as defined by the matrix section "Meaning of supported") or a verbatim fragment of the matrix, and `scripts/check_repository.py` enforces this mechanically (`check_skill_platform_view`). Harness cells draw only from the capability rows listed for that skill in the derivation map; operating-system cells draw only from the matrix OS section.

The OS columns carry the deterministic-gate granularity only. Per the matrix OS section, which this view quotes verbatim:

> This table covers the gate and the shipped runtime scripts; the harness rows above are OS-neutral claims about adapters and receipts and are not extended by it.
