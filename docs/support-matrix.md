# Support matrix

The maintained agent-harness set is **Codex, Claude Code, MiMo Code (`mimo`), DeepSeek Harness (`dsh`), and zcode**. All other harnesses, including Pi and Kimi Code, are unsupported by this project. A portable package may remain readable elsewhere, but that is not a support commitment. This matrix separates shared package behavior from host integration evidence: discovery, invocation, hooks, memory APIs, and optional integrations.

MiMo Code is the newly selected fourth target. Its 2026-10-26 local check establishes CLI identity and discovery of the fourteen canonical Skill names installed at receipt time (the repository catalog is twelve packages since the Super LLM Wiki and Super Lavish retirements); it does not establish model invocation, lifecycle hooks, MCP transport, or session-store parsing. Capability rows below retain those limits.

DeepSeek Harness is the newly selected fifth target. Its 2026-11-02 local check establishes desktop identity (`com.deepseek.dsh` 0.2.1-rc.5, Electron, bundled `dsh` profile launcher) and shared-user-root discovery of the pstack skills with zero broken links ([receipt](../evidence/deepseek-skill-discovery-2026-11-02.md)): all 68 skills resolve through `~/.agents/skills` from the skills-root tree, with dispatch surfaces `subagent`, `subagent_fork`, `spawn_teammate` and `workflow` registered in-session and no model-list surface exposed. It does not establish host-level skill invocation, lifecycle hooks, or session-store parsing. Capability rows below retain those limits.

## Meaning of “supported”

- **Supported**: implemented in the repository and covered by deterministic checks or a documented real adapter.
- **Host-dependent**: the runtime package is neutral, but the harness installation or tool surface must be verified.
- **Not claimed**: no audited implementation exists. It is not silently treated as equivalent.
- **Unsupported**: outside the maintained harness set for now, regardless of package portability or historical receipts.

Model quality is not a support claim. Benchmark comparisons must freeze the prompt, runtime package digest, time limit and tool permissions, then record attempt-1 evidence.
