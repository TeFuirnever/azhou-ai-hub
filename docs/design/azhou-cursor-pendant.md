# 阿舟官网指针挂件设计

这份文档从 RustWidget 提取跟随挂件的交互原理，并定义阿舟官网第一版。访客可在首页的指针试玩区开启挂件，移动鼠标时看到阿舟跟着走，停下后短暂摆动并归位。

## RustWidget 如何工作

参考版本为 [RustWidget `d9998dbe`](https://github.com/4evergr8/RustWidget/tree/d9998dbe6fd0aa2a3e586d6ae54d44c2c6b5bb01)。以下是源码和作者文档中的行为。Windows 桌面表现尚未实测。

| 上游机制 | Hub 的设计取舍 |
| --- | --- |
| RustWidget 读取 Windows 光标的位置和状态，用透明窗口将精灵画在光标旁。停靠模式保持固定偏移，挂件模式带绳子和摆动。 | 保留浏览器当前指针及其点击点。官网挂件只出现在既有试玩区。 |
| 鼠标加速度带动多段绳子。固定步长与渲染节奏分开，卡顿后限制补步。 | 用一根短绳和一个角度表现轻摆。鼠标水平移动给摆动一个有上限的推力。阻尼收住动作，归位后停止刷新。 |
| 光标状态选择精灵序列，缺少对应帧时回落到普通状态。 | 第一版用已有阿舟抱尾巴图作为挂件。箭头、链接、文本和抓取继续由现有试玩区展示。 |
| Win32 窗口、D3D11、托盘、全局热键和解锁重启服务于 Windows 常驻程序。 | 这些能力属于独立桌面产品。官网入口、设备判断和关闭都由浏览器处理。 |

上游依据见 [窗口循环](https://github.com/4evergr8/RustWidget/blob/d9998dbe6fd0aa2a3e586d6ae54d44c2c6b5bb01/src/main.rs)、[光标读取](https://github.com/4evergr8/RustWidget/blob/d9998dbe6fd0aa2a3e586d6ae54d44c2c6b5bb01/src/cursor.rs)和[摆动物理](https://github.com/4evergr8/RustWidget/blob/d9998dbe6fd0aa2a3e586d6ae54d44c2c6b5bb01/src/physics.rs)。

核对的上游版本没有找到代码或图标的复用许可。Hub 独立实现网页动效并使用[现有阿舟素材](../../site/assets/cursors/README.md)。上游代码、配置与素材的复用须有明确授权。 [GitHub 许可说明](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository)

## 访客看到什么

~~~text
阿舟 macOS 鼠标指针
下载鼠标指针主题 · 查看预览和安装步骤 · 恢复系统指针

[ 箭头 ] [ 链接 ] [ 文本 ] [ 抓取（按住） ]
[ 试玩跟随挂件 ]
~~~

- 刷新页面后，跟随挂件默认关闭。支持悬停和精细指针的设备显示一个可用键盘操作的开关，状态由按钮的 `aria-pressed` 表达。
- 启用后，开关提示访客把鼠标移到卡片上。访客把鼠标移入四张示例卡片所在区域，挂件才出现。靠近边缘时它换到指针另一侧或收进区域，绘制范围止于卡片格。移出、切换窗口、滚动或关闭时，挂件收起。仍处于开启状态时，下一次在卡片区移动鼠标可重新显示。
- 减少动态效果、强制颜色、纯触屏和脚本不可用时，访客仍能看现有指针预览。减少动态效果和强制颜色在浏览期间开启时立即撤下挂件。触摸和笔本身不驱动挂件。 [W3C 交互动效指南](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions)
- 挂件是装饰。它避开点击点，不接收指针事件或键盘焦点。测试涵盖安装链接、选中文字和按住抓取。

## 实现与状态

两种候选方案是用 JavaScript 重绘指针和挂件，或在现有指针之上单独显示挂件。采用叠加方案，页面继续使用已有光标样式、点击位置和交互。

首页模板提供试玩区、开关和装饰图。挂件由首页独立脚本控制，样式放在试玩区现有样式旁。脚本是开关和动效的唯一状态所有者。控制器保存开启状态、上一次鼠标的横坐标和当前摆动的角度、角速度及待处理的动画帧。CSS 约束覆盖范围并让事件穿透。状态只在当前页面生效。

默认采用本地试手感时选定的 80% 跟随速度、20° 摆幅和 120% 回稳速度。挂件首次出现时直接定位，后续位置变化使用 40 毫秒的缓出过渡。可见摆角上限为 20°，摆动和回稳以原弹簧模拟的 1.2 倍速度推进。

| 当前状态 | 事件 | 可观察结果 |
| --- | --- | --- |
| 关闭 | 开启 | 开关按下，等待鼠标进入试玩区。 |
| 开启 | 鼠标移动 | 挂件跟随并摆动。停止输入后，摆动归位。 |
| 开启 | 鼠标离开、滚动、窗口失焦 | 挂件隐藏，等待下一次区内移动。 |
| 开启 | 关闭或设备条件失效 | 挂件隐藏并清除待处理动画。恢复设备条件后从关闭状态开始。 |

macOS 的 `.cape` 下载和本地安装继续使用当前入口。如果后续需要 Windows 系统指针，原生主题是单独的交付目标。离开浏览器仍然跟随属于桌面挂件目标。 [现有 macOS 主题](../../assets/cursors/azhou-double-hug/README.md) · [Windows 原生指针格式](https://learn.microsoft.com/windows/win32/menurc/about-cursors)

## 验收

在本地构建的中英文首页启用、移动、关闭和再次启用挂件。检查角落、抓取、选字和主题下载。检查键盘、减少动态效果、强制颜色和窄屏触摸入口。保留一段从启用到关闭的本地浏览器演示，用于核对实际动效和版面。
