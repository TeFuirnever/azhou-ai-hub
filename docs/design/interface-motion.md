# 界面状态与动效

阿舟 Hub 的动效用来说明状态变化。交互一旦有结果，读者就能立即看到或操作。运动常量沿用官网已有的 120 毫秒反馈、160 毫秒状态过渡和 240 毫秒展开。进入与淡出使用 `cubic-bezier(.23, 1, .32, 1)`。跟手手势与用户调好的挂件保留各自的输入节奏。[Apple 动效指南](https://developer.apple.com/design/human-interface-guidelines/motion)

| 状态变化 | 采用的反馈 |
| --- | --- |
| 出现、消失、展开、收起 | 有完整开合能力时用成对过渡。兼容路径两边直接切换。低频对话框用透明度交代进出，高频数据区按实际数据立即显示或移除。 |
| 移动、拖动、改变尺寸 | 拖动直接跟手，固定布局在断点立即适配。暂停桌面挂件时先停止跟随，再淡出。恢复从当前透明度接上。 |
| 换内容、换图标、数值更新 | 搜索结果和实时数字立即更新。复制第一次成功时，勾用短透明度过渡出现。连续成功时保留确认状态。指针示例的两张姿态图用同一节奏切换。 |
| 按下、悬停、聚焦 | 按压和键盘焦点立即回应。只对指针悬停适用的状态使用悬停反馈。缩放限于开启动态效果时的短按压。 |
| 加载、完成、出错 | 快速操作直接显示结果。较慢操作用就地文字说明等待。发生失败时保留说明和后续动作。 |
| 系统减少动态效果 | 取消位置、缩放和带惯性的装饰运动。保留必要的文字、颜色、焦点和短淡入淡出。 |

本轮查看了官网、中英文首页和资源搜索、桌面挂件、Workbench 面板和仪表盘、Archify 阅读器与故事页面、Diagram Design 图库和 Brainstorming 模板。图解本身的演示动画遵循各自的叙事节奏。第三方内置组件继续使用各自的实现。

验收时记录内容何时可操作和能否打断。分别查看手机宽度、窄桌面、宽屏、深浅色与减少动态效果。滚动测量记录浏览器与机器、帧间隔、长任务和意外布局偏移。
