# Support

If your agent cannot find a skill you installed, [check skill discovery](docs/installation.md#check-that-your-host-finds-the-skill). For compatibility questions, [check what works in your agent host](docs/support-matrix.md).

| Need | Channel |
|---|---|
| Reproducible defect | [Report a bug](https://github.com/TeFuirnever/azhou-ai-hub/issues/new?template=bug.yml) |
| New skill or capability | [Skill request](https://github.com/TeFuirnever/azhou-ai-hub/issues/new?template=skill-request.yml) |
| Usage question or design discussion | [GitHub Discussions](https://github.com/TeFuirnever/azhou-ai-hub/discussions) |
| Vulnerability, secret, unsafe deletion or privacy exposure | [Private security report](https://github.com/TeFuirnever/azhou-ai-hub/security/advisories/new) |

For a bug report, name the skill or feature, describe what you did, and say what you expected and what happened. Include the agent host and version if you know them. Share a redacted example. If a check already failed, include its first error.

Community support is best effort. Maintainers may ask for a minimal synthetic fixture before investigating private or environment-specific behavior.
