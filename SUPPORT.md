# Support

Use the narrowest channel:

| Need | Channel |
|---|---|
| Reproducible defect | [Bug report](https://github.com/TeFuirnever/azhou-ai-hub/issues/new?template=bug.yml) |
| New skill or capability | [Skill request](https://github.com/TeFuirnever/azhou-ai-hub/issues/new?template=skill-request.yml) |
| Usage question or design discussion | [GitHub Discussions](https://github.com/TeFuirnever/azhou-ai-hub/discussions) |
| Vulnerability, secret, unsafe deletion or privacy exposure | [Private security report](https://github.com/TeFuirnever/azhou-ai-hub/security/advisories/new) |

Before reporting a bug, run <code>python3 scripts/verify.py</code> when working from a clone. For an installed skill, include the exact Git commit/tag, harness version, model, tool permissions and a redacted reproduction.

Community support is best effort. Maintainers may ask for a minimal synthetic fixture before investigating private or environment-specific behavior.
