# Selected-material reflection evaluation plan

Status: proposed; no behavior benchmark, independent review or workflow benefit has been established. The implementation tests are synthetic development checks, not a frozen independent evaluator. Before a candidate is evaluated, an evaluator who is not the candidate modifier must freeze the case files, expected evidence, rubric, model, host, tool policy, budget, candidate digest and stopping conditions in a fresh protected record. Do not reclassify development tests as a held-out evaluation.

Select at least 12 source-independent case groups, four each for development, validation and final holdout. Split by task and source and check exact and near duplicates. Natural authorized material is preferred; if unavailable, use synthetic groups and report the findings as exploratory. Do not import private transcripts into Git. Cover stable practices, changed goals, counterexamples, no common theme, effective practices, unknown source, repeated assistant speculation, tool failures misattributed to the user, missing history, no action needed and extra burden.

Use the same model, selected material and budget for independent fresh-context treatments A (ordinary summary and suggestions) and B (candidate reflection contract). On validation, C removes source-dependency and counterexample checks; without C, do not attribute any difference to those mechanisms. Alternate generation order; reviewers independently compare anonymous outputs with order reversed. Record model, host, known system context, tool policy, inputs, timings, token usage, retries, human corrections and actual cost or `unknown`. Uncaptured personalization limits attribution.

Score evidence fidelity, source independence, time calibration, explanation specificity, alternatives, action value and burden from 0 to 2, with case-specific examples fixed before evaluation. A sum cannot offset fabricated evidence, privacy leakage, executed injection or ungrounded personal diagnosis. Require all mechanical security and source negative controls to pass and no critical failure on the holdout. At least three independent named reviewers form an odd majority; the majority must rate B more useful, or equally useful with less burden, on at least three holdout groups, with no critical regression in any group. Failure is retained, not rerun selectively. A small sample supports at most a restricted pilot.

A user must explicitly adopt an experiment and provide comparable later task evidence before claiming a workflow improvement. Distinguish suggestion, adoption, attempted use, observed improvement, no improvement and inconclusive results; note differences in task, model and external conditions. Promotion and exact-diff human approval remain governed by `docs/skill-standard.md`.
